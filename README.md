# HYROX ウォッチ 🟢

日本＋アジアの **HYROX 開催情報とチケット販売開始** を毎日チェックして、
変化があれば **LINE** で知らせるスマホ用WEBアプリ（PWA）。二人（私と旦那）用。

## できること
- **⓪ 棚卸し / 新着**：現在決まっている開催を一覧。使い始めて以降は「新規開催」を新着表示。
- **① 判断**：各大会を **[行く][検討中][興味なし]** で仕分け。判断材料に
  **東京からの所要時間（✈️＋🚃）・フライト概算価格** も表示。
- **参加予定**：「行く」大会を **未開催（これから）／開催済み** に分けて表示。
- **② チケット追跡**：チケット状況・**販売開始日（海外は日本時間換算）**、
  **提携ジム先行の目安（一般販売の約24〜48時間前・日本/海外で注記）** を表示。
- **③ 通知**：更新があるたび LINE にプッシュ（毎日 昼12時・深夜0時 JST）。

## 構成（サーバーレス）
- `crawl.py` … RoxRadar から収集 → `events.json`（`travel.json` をマージ）
- `notify.py` … 前回との差分を検知 → LINE（任意でメール）通知
- `index.html` / `app.js` / `styles.css` … PWA（判断キュー・参加予定・一覧）
- `.github/workflows/update.yml` … 1日2回 収集→通知→GitHub Pages 公開
- `config.js` … LINE友だち追加URLの設定
